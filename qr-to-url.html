Convertir QR Code → URL cliquable

💡 À quoi ça sert ? Cette page vous permet de transformer un QR Code déjà créé en lien cliquable pour vos PDF. Importez simplement l'image du QR Code et vous obtiendrez l'URL correspondante.

2. URL cliquable générée ✅

📄 Comment l'utiliser dans un PDF :

  1. Word : Insérez votre image QR → Clic droit → Lien hypertexte → Collez l'URL
  2. Adobe Acrobat : Outils → Modifier PDF → Ajouter lien → Collez l'URL
  3. PowerPoint : Insérez le QR → Clic droit → Lien → Collez l'URL

💡 Résultat : Quand on clique sur le QR dans le PDF, la fiche s'ouvre directement dans l'application !
